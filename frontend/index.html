AI-Powered Smart Home Gesture Control

A full-stack system that uses real-time hand gesture recognition to control smart home appliances. Built with a dual-stage AI pipeline — MediaPipe for landmark detection and a custom MobileNetV2 CNN for gesture classification — all connected to a cloud Supabase database.

HTML5 / CSS3 JavaScript (ES6+) Node.js Express.js Python (Flask) TensorFlow / Keras MobileNetV2 CNN MediaPipe Hands Supabase (PostgreSQL)
🧠

Dual-Stage AI Pipeline

MediaPipe Hands detects hand landmarks geometrically, then a MobileNetV2 CNN classifies the cropped hand image for maximum accuracy.

⚡

Real-Time Processing

Processes live webcam frames with sub-500ms latency. A 3-frame vote buffer prevents false triggers for reliable gesture detection.

🔐

Secure Authentication

Supabase Auth handles user signup and login. Sessions are managed via Node.js Express routes with JWT token storage.

☁️

Cloud Activity Logging

Every gesture-triggered device change is persisted to a Supabase PostgreSQL table, providing a full audit trail accessible from anywhere.

🏗️

Full-Stack Architecture

Clean separation of concerns: browser handles UI & camera, Node.js Express handles auth & DB proxying, Python Flask handles ML inference.

📊

Dynamic Result Display

Prediction results, confidence scores, and device states all update dynamically in real time without any page reload.
